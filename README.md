### 📌 Featured Engineering Projects

# 🎓 Automated Internship Management & AI Career Matching Platform

A full-stack, AI-powered platform designed to streamline university internship placements, candidate screening, and compliance verification.

> 🚀 **Key Impact:** Reduced manual candidate screening time by **35%** through semantic resume parsing and automated match scoring.

## ✨ Core Features & Technical Highlights

* **AI-Driven Candidate Matching**: Utilized **OpenAI API** and vector/semantic search to parse unstructured student CVs and dynamically match applicants to posted internship roles based on skill compatibility.
* **Automated Document Processing Pipeline**: Built an asynchronous ingestion pipeline that extracts text from uploaded documents for auto-population while running automated background security/content scans.
* **Administrative Analytics Dashboard**: Engineered a real-time analytics hub providing university admins with metrics on student placement rates, employer participation, and industry hiring trends.

## 🛠️ Tech Stack

* **Frontend**: Next.js / React, JavaScript, Tailwind CSS
* **Backend**: Node.js, Express / Next.js Server Actions
* **Database & AI**: MongoDB, OpenAI API

# 📚 Science Faculty Syllabus & Course Approval Management System

An enterprise workflow automation system built for university science faculties to manage course creation, multi-level review, and compliance auditing.

## ✨ Core Features & Technical Highlights

* **Role-Based Governance & Auth**: Implemented secure authentication with fine-grained Role-Based Access Control (RBAC) to differentiate Program Heads, Faculty Members, and Reviewers.
* **Automated Notification & Tracking Pipeline**: Integrated transactional email systems for submission confirmations, review reminders, and approval status updates.
* **Approval Analytics Dashboard**: Designed dedicated tracking dashboards for Program Heads to monitor course pipeline statuses and approval bottlenecks in real time.
* **Automated PDF Export Engine**: Programmatically compiled approved course syllabi into standardized, compliance-ready PDF documentation.

## 🛠️ Tech Stack

* **Frontend**: React / Next.js, TypeScript, Tailwind CSS
* **Backend**: Node.js, PostgreSQL / Supabase
* **Services**: NodeMailer / Resend, PDF Generation Engine
